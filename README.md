# Landing Page
A stylish and responsive bike catalog website built using HTML, SCSS — showcasing bike models in a modern and clean layout, with support for adaptive design.

## Technologies used:
- HTML5 – for structuring the website content and providing semantic markup.
- SCSS – for writing modular and maintainable styles with variables, nesting, and mixins.
- BEM methodology – for organizing CSS classes in a clear and scalable way.
- Responsive Design – to ensure the website looks and works well on all screen sizes and devices.
